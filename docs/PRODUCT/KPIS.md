# KPIs & Metriken

- Aktivierung: Zeit bis „Schlag importiert“ (<5 min), % Nutzer mit ≥3 Maßnahmen/Woche
- Retention: WAU/MAU, Day‑30 Retention, Anzahl genutzter Module
- Wertnutzung: „Grüne Fenster genutzt“, NDVI‑Aufrufe/Schlag/Woche, exportierte Nachweise/Monat
- Wachstum: organische Referrals, Piloten → zahlende Konversion, ARPA

Telemetry‑Events (minimal): Import Schlag, Task erledigt, Export erzeugt, NDVI‑Ansicht geladen.
