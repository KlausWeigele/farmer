# Glossar

- Schlag: Abgegrenzte landwirtschaftliche Fläche (Feld) eines Betriebs
- NDVI/NDRE/EVI/LAI: Vegetationsindizes für Biomasse/Chlorophyll/Laubfläche
- ETRS89/UTM32/33: Bezugs-/Koordinatensysteme in der EU
- ISOXML (ISO 11783): Standard für Landmaschinen‑Daten (Taskdata, Boundary, Guidance)
- VRA: Variable Rate Application (Applikationskarten)
- RLS: Row‑Level‑Security (Zeilenebene) in Datenbanken
- COG: Cloud Optimized GeoTIFF
- BBCH: phänologisches Stadium von Kulturpflanzen
