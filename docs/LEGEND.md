# Legende & Tags

Kennzeichnungen (aus dem gemeinsamen Konzept):

- [MVP] = ins erste Release
- [PRO] = bezahltes/fortgeschrittenes Paket
- [ENTERPRISE] = große Betriebe/Kooperationen
- [DE] = Deutschland-/EU-spezifische Compliance
- [DIFF] = klarer Differenzierer gegenüber nationalen & internationalen Lösungen
- Hinweis: Keine rechtsverbindliche Agrarberatung; die App liefert Entscheidungs‑Unterstützung, Checklisten & Compliance‑Prüfungen (Sachkundenachweis bleibt erforderlich).

Konventionen:
- Tags direkt an Feature‑Titel anhängen, z. B. „Wetter‑Ampel [MVP][DIFF][DE]“
- Optionales Front‑Matter pro Datei/Feature:
  - status: planned | in_progress | done
  - id: F‑Kürzel (z. B. F-HOME-AMP-001)
  - owners: Team/Namen

IDs und Bezeichnungen:
- Feature‑ID: `F-<BEREICH>-<KURZNAME>-<laufende Nummer>`
- Story‑ID: `S-<EPIC>-<laufende Nummer>`
- Akzeptanzkriterium‑ID: `AK-<EPIC>-<Story>-<Buchstabe>`
