# Akzeptanzkriterien — Leitfaden

Prinzipien:
- Messbar, knapp, reproduzierbar; klare Vorbedingungen; ein Ergebnis je Kriterium
- Nutzer‑zentriert formulieren (Was kann der Nutzer in welcher Zeit/Qualität?)

Beispiele:
- Import 10 Schläge < 5 Min, Flächenabweichung <0,5 %, EPSG erkannt.
- PDF‑Export „Jahresübersicht“ <10 s, Prüfsumme/Hash im Footer.
- Offline: Flugmodus → Task+Foto speicherbar; Sync <30 s nach Netz.
- NDVI‑Detailansicht lädt <2 s bei 4G; wöchentliche Komposite vorhanden.
